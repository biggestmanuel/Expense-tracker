# Spendly — Expense Tracker

A public-facing, responsive expense tracker built with HTML, CSS and Vanilla JavaScript.

## Features
- Add and delete expenses
- Category filtering
- Total, monthly and average spending
- Category breakdown
- Local browser persistence with localStorage
- Input validation
- Future-date protection
- Responsive design
- Light/dark mode
- No external APIs, frameworks, databases or paid services

## Run
Open `index.html` in a browser. No build step is required.

For public deployment, upload the three files (`index.html`, `styles.css`, `app.js`) to a static host such as GitHub Pages, Netlify, or Vercel.

## Privacy
Expenses are stored only in the user's browser via localStorage. No account or server is used.

## Scope
This is a client-side public utility, not a bank-grade financial service. It does not provide cloud backup, multi-device sync, accounts, or server-side encryption.
